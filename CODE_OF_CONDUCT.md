# Código de conduta

## Compromisso

Este projeto é um espaço de construção coletiva. Participação é aberta a
qualquer pessoa, com ou sem experiência técnica, independentemente de origem,
gênero, identidade, orientação, deficiência, idade, religião ou posição social.

## Esperado

- Tratar quem participa com respeito, inclusive em discordância.
- Criticar ideia, código e proposta — não a pessoa.
- Explicar decisão técnica para quem está começando, sem desprezo.
- Assumir erro e corrigir em público, já que o registro é público.

## Inaceitável

- Assédio, ameaça, perseguição ou intimidação.
- Insulto, ataque pessoal e humilhação.
- Racismo, machismo, LGBTfobia, capacitismo e qualquer forma de discriminação.
- Exposição de dados pessoais de terceiros.
- Divulgação de golpe, token falso, pedido de chave ou phishing.
- Usar o projeto para promover investimento com promessa de retorno.

## Sobre o conteúdo político

O projeto tem posição estética e política declarada, e debate político faz parte
dele. Isso não autoriza ofensa: argumento é bem-vindo, ataque pessoal não é.

## Aplicação

Mantenedores podem editar, ocultar ou remover contribuição que viole este
código, e banir quem reincidir. Relatos podem ser feitos de forma privada pela
aba **Security → Report a vulnerability** ou abrindo issue, quando não houver
risco em tornar o caso público. Todo relato é analisado; a identidade de quem
relata é preservada.

Este código se aplica a todos os espaços do projeto: repositório, issues, pull
requests, site e canais oficiais de comunidade.

Adaptado dos princípios do Contributor Covenant 2.1.
